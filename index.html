ChemLab-Assets

203 simulation-ready chemistry laboratory instruments, for robots and LLM agents. The open-source project I build and maintain with collaborators at MBZUAI.

mbzuai-nlp / ChemLab-Assets

Agents that work in a chemistry lab need more than meshes. Every instrument here ships its geometry together with working joints, front-panel menus, an executable behaviour model, and a machine-readable contract.

A robot can operate an instrument by hand in a 3D simulator, or an LLM agent can run it from a shell, and the instrument behaves the same either way.

01 · Embodied mode

Robots operate the instruments

Doors, lids, sashes, keys, and knobs are real joints with grasp points and colliders. All 203 instruments were converted to USD and run in NVIDIA Isaac Sim, where the screen a robot sees is drawn by the instrument’s own menu engine.

02 · Agentic mode

LLM agents run the lab from a shell

One command, chemlab, puts the whole lab behind plain verbs with units and range checks. Errors say what is wrong and how to fix it, lab time moves only when the agent waits, and 276 tasks are scored by reading the instrument’s own state.

What I’m building

Building the last mile between AI and the physical world.

Chemistry is where I’m placing that bet: connecting what a model predicts with what happens in a real experiment. I’m pursuing two complementary routes toward that goal.

01Act in the physical world

Autonomous chemistry labs

I want to build labs where AI can plan experiments, coordinate automated equipment, and learn from the results.

The Agentic Model would be the lab’s decision-making brain, turning scientific goals into experimental steps and adapting to observations. A catalysis foundation model would provide specialized knowledge for reasoning about catalysts and reaction conditions. Lab automation would connect those decisions to physical experiments.

02Predict the physical world

Chemical reaction simulation

My second bet is a Simulation Model that models chemical reactions and aims to predict their behavior under real experimental conditions.

The goal is to explore how changes in catalysts and reaction conditions affect outcomes before running an experiment. Predictions would guide what to test in the lab, while experimental observations would help evaluate and improve the model.

  1. Simulate
  2. Experiment
  3. Learn

Together, these routes aim to connect prediction, experimentation, and learning: use simulation to guide experiments, then use physical evidence to improve the next prediction.
